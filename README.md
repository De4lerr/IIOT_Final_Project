# IIOT_Final_Project

The objective of the project is to implement an Android PID control APP to complete and complement the laboratory for the Linear Control discipline of the Mechatronics Engineering course at UFU. The project must communicate via MQTT through a BROKER as an intermediary between the APP as a publisher of PID parameters (Kp, Ti and Td) and an ESP32 as a subscriber, which also contains the code that controls the laboratory experiment itself.
