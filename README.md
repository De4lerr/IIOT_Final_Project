# IIOT_Final_Project

O objetivo do projeto consiste na implementação de um APP Android de controle PID, para a realização e complemento do laboratório da disciplina de Controle Linear do curso de Engenharia Mecatrônica da UFU. O projeto deve realizar uma comunicação via MQTT através de um BROKER como intermediário entre o APP como publisher de parâmetros de PID (Kp, Ti e Td) e um ESP32 como subscriber, sendo que esse contém também o código que realiza o próprio controle em si do experimento de laboratório.
